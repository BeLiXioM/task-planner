# Планировщик задач

Учебное приложение для управления повседневными задачами на HTML, CSS и JavaScript — без фреймворков и сторонних библиотек.

## Возможности

- Добавление задач с проверкой пустого ввода и удалением пробелов по краям.
- Отметка выполнения и зачёркивание выполненных задач.
- Подсчёт оставшихся активных задач.
- Редактирование названия с возможностью отмены.
- Удаление задач по уникальному ID.
- Фильтры «Все», «Активные» и «Выполненные».
- Сообщения о пустом списке и отсутствии задач для выбранного фильтра.
- Сохранение задач и выбранного фильтра в localStorage.
- Восстановление задач с проверкой типов данных.
- Обработка ошибок чтения сохранённого JSON.
- Необязательный срок выполнения с редактированием и сохранением.
- Выделение просроченных невыполненных задач.
- Отмена редактирования клавишей Escape.
- Обработка нажатий на вложенные элементы кнопок через closest().

## Технологии

- **HTML** — разметка, форма и элементы управления.
- **CSS** — оформление выполненных задач.
- **JavaScript** — работа с данными, DOM и событиями.
- **crypto.randomUUID()** — создание уникальных ID.
- **Делегирование событий** — обработка действий через общий список.
- **JSON и localStorage** — сохранение данных в браузере.
- **Git и GitHub Pages** — контроль версий и публикация.

## Локальный запуск

Требуется Node.js 26 LTS и npm.

1. Клонировать репозиторий и открыть папку проекта.
2. Установить зависимости: `npm ci`.
3. Запустить сервер разработки: `npm run dev`.
4. Открыть адрес, указанный в терминале.

В PowerShell при блокировке npm.ps1 используйте npm.cmd вместо npm.

## Сборка и публикация

- `npm run build` — сборка в папку dist.
- `npm run preview` — локальная проверка сборки.
- После push в main GitHub Actions автоматически собирает и публикует сайт.
- node_modules и dist не хранятся в Git.

## Структура проекта

- `index.html` — форма, фильтр, счётчик и список задач.
- `style.css` — стили приложения.
- `script.js` — управление задачами, отображение, события и сохранение.
- `task-utils.js` — фильтрация, подсчёт активных задач и проверка просрочки.
- `validation.js` — проверка данных задачи.
- `storage.js` — сохранение и восстановление задач.

## Об обучении

Проект создаётся в процессе изучения JavaScript с объяснениями, подсказками и разбором ошибок.

В работе закрепляются функции, массивы объектов, `filter`, `find`, `findIndex`, DOM, формы, области видимости и проверка данных.

Отдельное внимание уделяется всплытию и делегированию событий, `event.target`, `event.currentTarget` и атрибутам `data-*`.

## Ограничения

- Данные хранятся в текущем браузере и не синхронизируются между устройствами.
- При очистке данных сайта сохранённые задачи удаляются.
- Учётных записей и серверной части нет.
- Напоминания не реализованы.

Проект находится в разработке.
